# Branchout

**把收集到的内容，放回你正在构建的项目中理解。**

Branchout 是一款本机桌面应用。你为本机 Git 项目写下关注卡，再通过应用内添加链接或 Telegram 转发内容。每份内容报告保留来源正文、图片与通用理解，并指出它和哪些活跃关注卡相关。项目分析读取仓库、近期 commit 和选定的本机 Codex 工作对话，生成可审阅的关注卡建议。

## 当前能力

- **项目与关注卡**：绑定本机 Git 仓库，按项目创建、编辑、暂停和启用自由文本关注卡。卡片版本与历史项目可回看。
- **内容报告**：提交 GitHub 公开仓库、X 帖子或小红书笔记链接。报告展示实际读取的来源范围、内容理解及有依据的关注卡关联；关联结果允许零条。
- **Telegram 接入**：在设置中配置 Bot 并授权聊天。Bot 持久化单条链接后发送收取确认，桌面应用处理队列，完整报告在应用内阅读。
- **项目分析**：选择最近 30 或 100 条 commit，并审阅与仓库关联的 Codex 会话范围。分析报告呈现输入覆盖、发现、证据与新增或修改关注卡的建议；建议由你逐条接受。
- **任务后台**：查看转发与项目分析的阶段、进度和近期活动，打开结果并处理失败任务。
- **模型与来源设置**：使用通用 API 或 Codex 订阅账号作为当前模型连接，配置 X 与小红书的读取环境。凭据由本机安全存储管理。

Codex 对话在进入模型前由固定代码解析。项目分析使用用户发言和必要的最终助手回复；报告记录引用位置及实际覆盖范围。

## 本地运行

需要 Node.js 24 或更新版本。在仓库根目录执行：

```bash
npm install
npm run dev
```

首次读取 X 或小红书内容前，分别运行 `npm run setup:x` 或 `npm run setup:xhs`，随后在应用的“设置”中完成连接。GitHub 公开仓库 README 可直接读取。在“设置 → 模型连接”保存当前模型后，从“项目”绑定仓库并创建关注卡，再从“内容”添加链接。

应用把项目、报告、任务和设置保存在本机。窗口关闭后，仍运行的应用进程继续处理已入队任务；再次打开窗口时可查看任务状态。
