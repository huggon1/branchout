# Feedloom

Feedloom 把跨平台内容组织成围绕 Topic 持续生长、可追溯来源、具有个人表达风格的 Feed。

## 当前形态

桌面网页产品 Pitch 讲解稿：七页短文配合应用界面，展示转发解析、Topic 配置、博主风格提取、跨平台收集、内容编排和 Feed 阅读。默认有准备好的结果，翻页即可看完整流程；少量交互用于体验关键变化。

演示页集中展示最终可能分布在手机、其他平台和后台的操作，不代表最终产品导航。Topic 提前绑定 Profile，收集与生成既可分段讲解，也可连续模拟。

## 本地运行

需要 Node.js 22 或更新版本及 npm。

```sh
npm install
npm run dev -- --port 4317
```

打开终端给出的本地地址。页面面向桌面显示，建议浏览器宽度至少 1280px；不包含移动端布局。

```sh
npm run check
```

检查包含模型行为测试、TypeScript 检查和生产构建。浏览器流程测试见 [tests/demo.spec.ts](tests/demo.spec.ts)，安装 Google Chrome 后执行 `npx playwright test`；测试会自动启动独立的本地服务。文档检查使用 `git diff --check`，并验证仓库内链接。

## 模拟边界

- 所有内容、博主、项目与运行都是虚构样例，不接入真实平台或模型。
- 模拟解析、收集、风格提取和生成使用确定性数据与模板。自由填写的 Topic 不会触发真实研究；没有匹配素材会显示无结果。
- 频率用于展示配置，不会在后台定时执行；“立即模拟一次”回放一次运行。
- Feed 通过稳定标识关联原始素材与收集记录；运行保存当时的 Profile。
- 浏览器本地保存演示状态；页面提供恢复初始样例的入口。禁用存储时仍可进行当前会话。
- 不包含真实搜索、登录、通知、版本管理或完整后台管理。

## 实现边界

[src/model.ts](src/model.ts) 保存内部对象、虚构素材和确定性模拟函数；[src/main.tsx](src/main.tsx) 组合讲解页面与界面交互。正式模块契约与真实平台适配器属于后续阶段。
