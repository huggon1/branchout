# Feedloom

Feedloom 把来自不同社交平台的内容，组织成围绕用户 Topic 持续生长、可以追溯来源、能够按不同 Creator Profile 呈现的个性化 Feed。

## 当前状态

仓库目前处于项目初始化阶段，尚无可运行应用。

第一阶段交付物是一个由确定性假数据驱动的完整网页应用 Demo。它通过多页面导航、内容与 Topic 管理、收集运行、Creator Profile、Agent 生成和 Feed 阅读，验证产品形态与整体体验。

Demo 中的模拟能力必须明确标记，不能被误认为已经完成的真实平台接入。

## 核心能力

- 接收并解析用户转发的社交平台内容；
- 围绕用户维护的 Topic 定时收集信息；
- 从创作者历史内容生成可调整的 Creator Profile；
- 根据收集结果和 Creator Profile 生成可追溯的 Feed；
- 展示 Agent 运行状态、生成依据和产物版本。

## 开发原则

- 先验证完整产品体验，再冻结模块协作契约；
- 先复用已有仓库和工具跑通真实链路，再分模块优化；
- 平台能力位于可替换的适配器边界之后；
- 每条生成内容都保留到原始内容和收集运行的依据；
- 登录态、密钥和私有运行数据不进入 Public 仓库；
- Demo 数据保持确定、连贯、可重置，并覆盖成功与失败状态。
