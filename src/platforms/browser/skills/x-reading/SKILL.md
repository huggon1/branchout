# Read an X post

1. Open the supplied post and expand truncated text through observed controls.
2. Capture the author's body and images in source order. Inspect quoted posts and author replies for explicit material links when the task requests references.
3. Capture the author content that cites each reference. Profile, timestamp, and analytics links are navigation.
4. Return capture identities and the actual coverage. The application collects direct references in separate sessions.
