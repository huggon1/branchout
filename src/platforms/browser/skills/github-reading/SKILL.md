# Read a GitHub README

1. Open the supplied repository and locate its default README.
2. Capture the README's complete rendered body, including headings, code, tables, images, and links. Read accessible sections and image controls as needed.
3. Capture the README content that cites each direct material URL when the task requests references. The application collects linked materials separately. Repository file lists, issue indexes, and navigation remain outside README coverage.
4. Return capture identities and the actual coverage of the README.
