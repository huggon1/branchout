# Platforms

## 职责与运行位置

`platforms` 提供统一的平台搜索、详情读取、配置和能力状态接口，由 Agent 工作进程通过工具层调用。平台适配可以调用不同语言或独立运行的第三方工具，不要求全部使用 TypeScript。

## 允许依赖

- Node.js 网络与进程能力；
- 平台所需的第三方 SDK、命令或服务；
- `shared` 中与任务传递有关的稳定数据类型。

平台层不依赖 Pi、React、桌面主进程业务或本地数据存储。

## 文件蓝图

- `types.ts`：定义搜索、详情读取、配置和能力状态的统一接口。
- `registry.ts`：登记适配器并按平台和能力选择实现。
- [adapters](adapters/README.md)：保存具体平台适配。
