# 平台适配

## 职责与运行位置

`adapters` 保存具体平台实现，在 Agent 工作进程需要平台能力时运行。每个平台只实现自身支持的搜索、详情读取、配置和能力状态，并通过上级 `types.ts` 的统一接口暴露。

## 允许依赖

- 上级平台接口；
- 该平台所需的 SDK、命令或外部服务封装；
- 平台内部的数据规范化辅助代码。

适配器不依赖 Pi、React、桌面主进程业务或其他平台实现。

## 组织规则

每个接入平台使用一个目录，目录中的关键文件按以下职责组织：

- `index.ts`：实现并导出平台适配器。
- `client.*`：封装平台 SDK、命令或服务调用；只有需要时才创建。
- `normalize.ts`：把平台结果转换成统一结构；只有存在独立转换职责时才创建。

多个平台共用的能力放在上级目录，不在适配器之间相互导入。
