# 探索方案

## 职责与运行位置

`plans` 由 Agent 工作进程读取，定义产品探索和 UI/UX 探索各自的平台范围、搜索步骤和筛选规则。这里表达可执行方案，不保存平台接入实现，也不重复产品规格。

## 允许依赖

- `shared` 中的稳定领域类型；
- `platforms/types.ts` 暴露的平台能力类型。

方案不依赖 React、桌面主进程或 Pi 的具体接口。

## 主要文件

- `index.ts`：按探索方向组织搜索概念与平台范围，供探索任务使用。

每个方案只能从产品规格确定的首批平台 X、小红书和 GitHub 中声明自己的平台范围，不要求两个方向使用完全相同的平台。具体映射和搜索方式可以根据效果调整；共用规则留在本目录，平台调用细节留在 `platforms`。
