# Branchout

**收集链接，用自己的语言阅读，找到值得关注的讨论。**

[English](README.md)

看到想留着读的帖子或文章时，把链接交给 Branchout。它会用你选择的语言生成阅读报告，包含主内容、直接引用材料，以及每份材料的简短摘要。本机 Git 项目的**关注卡**用于搜索相关讨论。项目分析还能从仓库和你选定的 Codex 工作对话中提出新的关注角度，供你审阅。

![文章与两张相关关注卡建立联系的插画](assets/branchout-hero.png)

## 🧭 怎么使用

1. 在设置中连接模型并选择应用语言。在内容页添加一条链接，或转发给已配置的 Telegram Bot。
2. 以目标语言阅读每份材料的摘要和正文；处理失败后，可以继续处理未完成材料。
3. 使用讨论搜索时，绑定本机 Git 仓库，写一张关注卡，说明关心的场景、困难和期待。例如：“离线保存草稿失败时，希望看到原因，并在保留输入的情况下重试。”

## ✨ 你可以做什么

- **维护项目与关注卡**：绑定本机 Git 仓库，手写、编辑、暂停或重新启用关注卡，保留卡片版本。
- **阅读内容报告**：提交 HTTPS 文章、帖子或仓库链接。以目标语言阅读主内容与直接引用材料，保留图片、代码、表格和 Mermaid 图。同语言内容忠实呈现，其他语言内容翻译后呈现。每份材料显示实际获取范围。历史报告保留已保存的关注关联。
- **用关注卡搜索**：通过 X 的 Grok 或小红书的点点 AI 搜索讨论。报告保留平台回复，选中的帖子可以加入阅读。
- **从 Telegram 收集链接**：在获准聊天中发送单条链接，收到入队确认；完整报告在桌面应用中阅读。应用再次打开时继续处理 Telegram 仍提供的积压消息。
- **分析项目**：选取相关 Codex 工作对话，Agent 用只读工具探索本地仓库；核对 README 承诺与实现、测试和文档情况，查看关注卡建议，并逐条审阅、接受建议。
- **查看任务进展**：在任务后台查看当前阶段、近期动作、结果与失败原因。

项目、卡片、报告和任务保存在本机。模型任务会读取本次所需的来源内容或选定的项目材料，并交给你配置的模型连接处理。

## 来源访问

转发与关注搜索共用 Chrome 运行环境和已保存的网站登录。浏览器可以跨站读取可访问的 HTTPS 网页。平台说明和可选的小红书增强工具提供额外帮助。登录、验证和页面结构决定实际获取范围。

| 来源             | 阅读范围                                 | 关注搜索      |
| ---------------- | ---------------------------------------- | ------------- |
| 网页文章         | 可读取的正文和直接引用材料               | —             |
| GitHub           | 仓库默认 README                          | —             |
| X                | 帖子正文、图片、引用帖子和作者提供的链接 | Grok，英文    |
| 小红书           | 可读取的笔记正文和图片                   | 点点 AI，中文 |
| 音视频与交互页面 | 已有文字稿，或可读取的页面文字和图片     | —             |

阅读处理一层明确提供的材料链接。每份引用材料继续保留其中的链接。搜索逐张关注卡运行，可选近 1 天、1 周或 1 个月。[提示词流程](docs/agent-prompt-flow.md)说明共用工具和各类任务说明的关系。

## 从源码运行

开发需要 Node.js 24 或更新版本：

```bash
npm ci
npm run dev
```

浏览器和读取组件的准备方式见[开发指南](docs/development.md)。

打开应用后，在“设置”中连接通用 API 或 Codex 订阅账号。Codex 订阅连接使用本机可用的 Codex 命令行程序。从“内容”页添加链接即可开始阅读。绑定本机 Git 仓库并写下关注卡后，可使用项目分析和讨论搜索。X 和小红书内容需在设置中完成对应登录；Telegram 转发需先配置 Bot 并授权聊天。
