# Branchout

**通过平台 AI 寻找社媒内容，把转发的链接整理成可读材料。**

[English](README.md)

Branchout 是一个社媒内容获取与阅读桌面应用，提供两套功能：

- **平台 AI 搜索**：用自然语言描述问题，选择信息源，保存各平台的原始回答和来源链接。搜索条件可以保存为定期运行的关注。
- **转发解析**：手动提交链接，或通过 Telegram 转发链接，读取来源内容并整理为所选语言的阅读材料。搜索结果中的链接也可以加入同一解析流程。

## 平台 AI 搜索

| AI 搜索入口 | 信息源 |
| ----------- | ------ |
| X 内的 Grok | X      |
| 点点 AI     | 小红书 |

你可以输入带有场景和条件的问题，例如：“最近一周，独立开发者如何验证产品需求？我想找包含实际失败经验的讨论和原帖。”

Branchout 将问题适配为对应入口的语言，向所选平台 AI 发起单轮搜索。每次运行独立保存原问题、平台回答和带标题的来源链接。时间范围随问题交给平台 AI，来源日期以实际获取的信息为准。成功取得的结果会保留，失败的平台会显示原因。

在“搜索结果”中查看报告，打开原链接，或选择需要的内容加入解析。把搜索条件保存为关注后，可以设置每天或每周的运行时间，后续结果也保存在这里。定期关注在应用运行时执行，应用关闭期间错过的计划跳过。

## 转发解析

在“解析结果”中添加 HTTPS 链接，或将链接发送给已配置并授权的 Telegram Bot。Branchout 读取主内容及其直接引用材料，保存来源快照、简短摘要和所选语言的正文。

| 来源／内容类型 | 解析目标                                     | 能力说明                                                                                                        |
| -------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 通用网页       | 可访问的正文、图片及直接引用材料             | 基础浏览器读取；内置页面捕获将选定内容保存为 Markdown，并缓存可获取的图片                                       |
| X 帖子         | 帖子正文、图片、引用帖子和作者提供的材料链接 | 基础浏览器读取；内置 X 阅读 Skill 帮助展开正文、查看图片并识别作者提供的材料                                    |
| 小红书笔记     | 可访问的笔记文字和图片                       | 基础浏览器读取；内置笔记阅读 Skill；安装可选外部组件 `xiaohongshu-mcp` 后，可增强读取图文笔记的标题、正文和图片 |
| GitHub 仓库    | 仓库默认 README                              | 基础浏览器读取；内置 GitHub 阅读 Skill 将读取目标限定为默认 README                                              |
| 交互页面       | 可访问的文字、图片和嵌入页面内容             | 基础浏览器读取；内置浏览器工具支持页面交互和可访问 frame 的内容捕获                                             |

解析沿主内容明确提供的材料链接读取一层引用。阅读材料保留标题、段落、图片、代码、表格和链接；其他语言的正文翻译为本次选择的语言。每份材料显示实际获取范围，处理部分失败时仍可阅读已保存的内容。

两套功能共用 Chrome 和已保存的网站登录。实际获取范围取决于登录状态、平台验证和页面可访问内容；报告会呈现需要登录、人工验证或访问受限等情况。增强组件的准备方式见[开发指南](docs/development.md)。

## 开始使用

1. 在设置中连接通用 API 或 Codex 订阅账号，并选择应用语言。配置的模型负责浏览器操作、正文翻译和材料导读；平台 AI 搜索使用上表中的入口。
2. 在设置中登录需要使用的平台。
3. 选择一种方式开始：在“搜索”中输入问题，或在“解析结果”中添加链接。使用 Telegram 转发时，先配置 Bot 并授权聊天。
4. 在“搜索结果”和“解析结果”中阅读内容；在“关注”中管理定期搜索，在“任务”中查看运行状态、失败原因并导出 Pi 原生日志。

## 安装与更新

从已发布的 [GitHub Release](https://github.com/huggon1/branchout/releases) 下载 macOS Apple silicon DMG，将 Branchout 拖入 Applications 并打开。安装包使用项目签名；首次打开时，macOS 可能要求在“隐私与安全性”中确认。0.1.0 是新发布线的起点，旧版用户需要手动安装一次。后续版本会在“设置 → 应用更新”中显示，你可以下载，并选择在当前任务结束后安装。本机数据和平台会话继续使用原有目录。具体行为见[更新规格](docs/product-spec.md#application-updates)。

## 本机数据

报告、关注、任务状态和网站会话保存在本机。执行所需的问题和材料会发送给你配置的模型连接；平台 AI 搜索还会将适配后的问题发送给所选入口。存储与升级规则见[数据契约](docs/data-contracts.md)。

## 从源码运行

使用 Node.js 24 或更新版本：

```bash
npm ci
npm run dev
```

[开发指南](docs/development.md)说明浏览器准备、独立开发数据、检查和打包方式。Codex 订阅连接通过本机可用的 Codex CLI 建立。
