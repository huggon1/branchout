# Branchout UX 规格

产品范围和业务规则以 [产品规格](product-spec.md) 为准。本文规定任务界面的信息层级、页面行为与主要流程；共用视觉和操作规则见 [设计系统](design-system.md)。主要入口由窄左导航组织：素材、UI/UX、功能模块、项目和设置。

## 素材列表与阅读流

应用打开后进入统一素材列表。用户通过名称浏览素材，并按类别、来源、项目或时间寻找阅读起点。转发素材优先显示来源标题；标题未知时使用来源身份或链接命名。节点分析素材以节点和目标仓库组成可识别名称，并标明所属项目与方向。列表顶部提供搜索、筛选和“开始阅读”，操作对应当前筛选结果。

“开始阅读”从当前结果的第一条素材进入阅读流；点击具体素材从该条进入。素材页另提供轻量的“添加链接”入口，用户粘贴链接后开始转发处理。

阅读流一次聚焦一条素材。顶部稳定提供“返回列表”“上一条”和“下一条”，并显示当前位置。正文滚动用于阅读当前素材；用户通过顶部操作切换素材。退出阅读流后，列表恢复原筛选条件和浏览位置。

转发素材先呈现来源身份、获取完整性和原链接，再呈现正文、图片与独立的 AI 通用理解。内容获取有缺失或完整性未知时，在正文附近说明已知范围或原因。节点分析素材先呈现本项目、方向、节点与目标仓库，再呈现对应做法、差异、结论及其证据；找不到对应功能时，展示检查范围与判断结果。两类素材共用阅读导航，各自使用适合内容的主体结构。

节点分析素材提供两类来源入口：一类回看生成分析时的图版本与节点资料，另一类打开目标仓库本次分析所依据的提交和文件。旧图节点的入口保留在历史素材中。

## 项目管理

项目界面列出已添加的本机 Git 项目，并提供添加和删除操作。项目图、节点资料与仓库分析在各自的方向入口中使用；项目界面保持为简洁的管理入口。

## UI/UX 与功能模块工作区

两个方向各自有独立的工作区。用户进入方向后选择本机项目；该方向首次使用此项目时，界面显示图生成进度，完成后进入项目图。再次进入时直接显示当前图。项目切换保留在工作区内，使方向和当前项目始终清楚可见。

工作区以项目图为主内容，展示图生成时间及对应的项目状态，并提供“重新生成”。重新生成完成后显示新图；原图与旧素材的关系以 [产品规格](product-spec.md#项目图) 为准。用户可以在当前图上继续探索，按需要手动更新。

图保留 Archify 的动态呈现、缩放、节点聚焦和路径查看。点击节点时，图突出选中节点，右侧打开节点侧栏；切换节点时侧栏随之更新。侧栏与图同时可见，画布在可用空间内保持可读和可操作。

## 节点侧栏与仓库分析

节点侧栏首先显示节点名称和简述，然后显示是否适合分析及原因。事实与来源依据默认折叠，用户可以展开核对；来源指向生成该图时保存的节点依据。

适合分析的节点显示固定的“分析说明”，说明输入仓库后将比较的内容；其下提供公开 GitHub 仓库链接输入和“分析仓库”操作。其他节点显示暂不适合分析的原因与不可用的分析入口。侧栏的信息与操作始终对应当前选中的节点。

用户提交仓库后，工作区显示该次任务的进展和结果入口。分析完成时，用户可以打开生成的素材阅读；素材也进入统一列表。未找到对应功能、证据不足和读取失败分别使用明确的结果文案，阅读页保留检查范围。

## 设置与来源配置

设置界面分开呈现模型连接、转发渠道和内容平台。模型连接用于图生成、仓库分析和转发理解；飞书与 Telegram 是接收链接的渠道；内容平台负责读取转发链接指向的内容。

### 模型连接

模型连接区域显示一个当前连接，提供“通用 API”和“Codex 订阅账号”两个选项，并展示当前选择的配置表单。

通用 API 表单包含 API Key、服务地址、接口类型和模型标识。API Key 以密码输入，保存后显示“已配置”状态；接口类型提供 OpenAI Responses 和 OpenAI Chat Completions。

Codex 订阅账号表单在未登录时提供“登录 ChatGPT”；登录后显示账号状态、模型选择和“刷新模型”。模型来自当前账号与 Codex 客户端可用列表。刷新失败时保留已选模型并显示失败原因。

保存后，界面显示连接方式、模型和可用状态，并提示新连接供后续任务使用。正在运行的任务继续使用启动时的连接。

### 转发渠道与内容平台

飞书和 Telegram 分别显示配置状态，提供配置或重新连接操作。应用内“添加链接”位于素材页。

内容平台列表显示 X、小红书和 GitHub 的转发内容读取状态及相关配置入口。用户展开平台后查看配置说明并完成所需设置。节点分析所用的公开 GitHub 仓库链接在节点侧栏输入。

## 运行状态

图生成、仓库分析和转发解析任务显示所属项目或链接、当前阶段、结果及需要用户处理的状态。任务进行中保留稳定的进度入口；失败、取消与重试操作出现在对应任务旁。

关闭并重新打开窗口后，界面恢复正在运行的任务状态和已经保存的素材结果。仓库分析与转发解析各自显示进度，用户可继续浏览其他入口。
