# Branchout 0.1.0

Branchout starts a new release line with two workflows: search through platform AI and turn submitted links into readable material.

## What's included

- Search through Grok within X and 点点 AI within Xiaohongshu. Each report presents the original platform answers and their source links. Selected sources enter parsing directly.
- Save search conditions as daily or weekly follows. Runs made while Branchout is open produce independent reports.
- Parse links submitted in the application or forwarded through an authorized Telegram chat. Read source snapshots, translated text, images, and short introductions, including directly referenced materials.
- Use bundled reading skills for X posts, Xiaohongshu notes, and GitHub repository READMEs. The macOS package includes the Xiaohongshu image/text note reader.
- Read Search results and Parsed content separately. Focus manages recurring searches. Tasks shows execution state and exports native Pi logs. Settings manages model connections, platform login, language, and browser visibility.
- Download later versions inside the application and install after current work finishes. Browser work runs headless by default; platform login opens a window.

## Installation and migration

The DMG targets macOS Apple silicon. Install Google Chrome, move Branchout into Applications, and open it. Packages use a project signature; macOS may require approval through System Settings → Privacy & Security → Open Anyway. Then connect a model and sign in to the desired platforms in Settings. Codex subscription connections use a locally available Codex CLI; general API connections use the configured endpoint and model.

Users of the previous 0.4.0 build install 0.1.0 manually. The first launch clears previous-generation test reports, projects, cards, and tasks. It retains model and Telegram credentials, authorized chats, and platform session directories. Current-generation reports created during the refactor remain available. The [data contract](https://github.com/huggon1/branchout/blob/v0.1.0/docs/data-contracts.md#telegram-queue-and-business-reset) owns the reset rules. Subsequent upgrades retain current-generation data through the application's update flow.

## Retrieval coverage

Platform login, human verification, and accessible page content determine retrieval coverage. Search reports retain saved answers when source extraction fails. Parsing retains available material and shows its actual coverage.

Schedules run while the application is open; missed occurrences expire. The [README](https://github.com/huggon1/branchout/blob/v0.1.0/README.md) describes supported search entries and parsing targets.
