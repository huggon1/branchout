# Postrove 0.1.2

Postrove 0.1.2 simplifies model connection setup and refines workspace headings and spacing.

## Improvements

- Choose Built-in provider or Custom provider when creating a model connection. Custom setup loads models.json before authentication and model selection. Saved connections restore their setup method.
- Keep the active saved connection while preparing another connection. Saving applies the selected connection to later tasks.
- Read pages with fewer repeated headings and tighter spacing. Saved content and search results retain their object titles, including in narrow windows.

## Upgrading from 0.1.1

Install the update through Settings → Application updates, or download the macOS Apple silicon DMG from this Release. The upgrade retains saved content and platform sessions.

Existing native Pi connections retain their saved settings and credentials. Existing general API settings migrate into Pi with their endpoint, key, and model.

If your connection still uses the older Codex CLI integration, open Settings, choose the built-in OpenAI Codex provider, complete Pi authorization, and save the connection before starting a new task. The older CLI connection files remain on disk as inactive records.

## Windows installation trial

Windows x64 installation packages are available through the [Checks workflow](https://github.com/huggon1/postrove/actions/workflows/checks.yml) artifacts. The [development guide](https://github.com/huggon1/postrove/blob/main/docs/development.md#create-a-windows-installation-trial) describes installation, verification, and trial scope. Windows trial updates use a replacement installer.
