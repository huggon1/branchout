# Postrove 0.1.1

Postrove 0.1.1 adds Feishu link collection, native Pi model connections, and controls for task history and saved content.

## What's new

- Collect links through a Feishu application bot. Connect the bot in Settings, authorize a direct chat, and send an HTTPS link to add it to parsing.
- Choose Pi-supported providers, models, and authentication methods. Save multiple connections and set reasoning separately for browser and reading tasks.
- Open the global task panel from the header to view progress, failure reasons, saved results, and native Pi logs. Clear individual or all ended tasks while keeping saved content.
- Delete parsed results, search results, and task records independently. Each deletion offers Undo for eight seconds.
- Set up Telegram through a step-by-step guide for Token verification and chat authorization.
- Read shorter interface messages with fewer repeated explanations.

## Upgrading from 0.1.0

Install the update through Settings → Application updates. The macOS Apple silicon DMG is also available from this Release. The upgrade retains saved content, connections, and platform sessions.

Existing API connections migrate automatically with their endpoint, key, and model. Existing Codex connections remain active until you sign in through Pi and save the native connection. Returning to an older application after migration can require reconnecting the model account.
