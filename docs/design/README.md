# Brand assets

The app uses a folded-leaf silhouette with a soft-yellow facet and neutral ink facets on a white-gray rounded background.

![Branchout folded-leaf icon](../../assets/branchout-icon.svg)

- [App icon master](../../assets/branchout-icon.svg): vector input for PNG and ICNS builds.
- [README illustration](../../assets/branchout-hero.png): one article connected to two focus cards, using white paper, ink lines, and restrained yellow accents.
- [Interface mark](../../assets/branchout-mark.svg): transparent version for the navigation rail.
- [Design contract](../../design.md): authoritative color, typography, geometry, and interaction rules.

Both root READMEs reference the app icon master and README illustration directly. The PNG exploration files in this directory preserve historical design work. Build scripts read the current SVG assets.
