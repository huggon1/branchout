# MVP 页面设计评审

五个页面沿用已确认的白色、冷灰与蓝色视觉方向。图中旧术语、平台示例和数量配置不是功能约束；实现采用 PRD 的素材用语、三平台与各平台独立上限，增加连接与模型设置入口。当前桌面实现进一步加强字号对比、内容层级、表单草稿状态、候选依据及 Markdown 阅读；下列图作为视觉方向参考，不覆盖新增的意图收集交互。下列图为已确认的静态设计稿，内容和平台配置均为虚构示例，不代表已实现能力。功能规则以 [MVP PRD](../mvp-prd.md) 为准。

## 转发收件箱

左侧记录、右侧阅读。展示链接输入、正文、图片、AI 摘要、部分解析和失败重试；无任务归属或 Feed 生成入口。

![转发收件箱](forward-inbox-v1.png)

## 收集任务

任务列表与编辑区并排，所选任务下展示收集记录。配置与生成提示词分离；收集部分成功时，保留成功平台素材并允许重试失败平台。

![收集任务](collection-tasks-v2.png)

## 素材库

紧凑表格展示来源指标和摘要，跨日期素材分别保留；已用标记、半选状态和摘要失败不遮挡原始信息。排序菜单在选择单个平台时提供原生指标选项，图中显示默认时间排序。

![素材库](collection-library-v2.png)

## Feed 生成

素材列表与已选清单、提示词并排。重复来源只提示；半选状态与 3／6 条勾选一致。

![Feed 生成](feed-generation-v2.png)

## 我的 Feed

左侧历史，右侧宽松阅读。展示两条生成成功、一条失败；可复制成功内容或单条，失败可重试，来源与收集记录保留。

![我的 Feed](my-feed-v1.png)

## 评审结论与使用边界

- 已检查五项导航及核心术语、选中数量、重复来源处理、提示词归属、原始信号和失败状态的一致性。
- 图中 GitHub、Hacker News 与示例门槛不构成实际可用性承诺；收集平台须经过接入验证。
- 图展示代表性状态，不覆盖所有菜单、弹窗或滚动区域。原始链接、作者、发布时间、任务关系和完整依据在详情中查看；图中短日期仅用于节省列表空间。
- 素材库全选仅作用于当前筛选结果，切换筛选保留已有勾选；生成顺序需在已选清单明确呈现。
- 空列表、无匹配、进行中、全部失败、删除及重新生成的操作规则见 PRD；生图不代替交互验收。
- 本页五张图为已确认的 MVP 页面设计参考。
